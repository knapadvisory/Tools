Every tool, one address

All the utilities built for the practice, parked under one link. Web apps open in a tab; desktop tools download and run next to Tally on your own PC — the books never leave your machine.

First-time setup for the Tally tools (one time per Tally PC)

  1. Install Node.js (LTS) from nodejs.org.
  2. In Tally Prime: F1 (Help) → Settings → Connectivity → Client/Server configuration → TallyPrime acts as = Both, Port = 9000. Keep the company open.
  3. Install the KNAP Tally Connector (below): put it in its own folder and double-click. It starts with Windows and updates itself. One connector powers the GSTR-2B, Audit, TDS, Financials and Debtor/Creditor tools.
⬇ Download connector 🔒 Runs entirely on your PC — books data flows browser ↔ connector ↔ Tally locally and never leaves the machine.
