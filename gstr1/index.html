GSTR-1 → Excel summary ← All tools

Drop the monthly GSTR-1 files (GST portal download — PDF and/or JSON) and get the “As Per GSTR1” table — B2B / B2C / Export / IGST / CGST / SGST, one row per month — as an Excel file.
JSON files also give section-wise bill sheets for the year — B2B bills, B2B credit/debit notes, exports, B2C — with party GSTIN & name, monthly subtotals, and a separate Amendments sheet whose effect is included in the summary.
GSTR-3B PDFs can be dropped too — you get a GSTR-1 vs GSTR-3B difference sheet (3B B2B+B2C and Export separately) and an RCM sheet from Table 3.1(d).

    Files are processed on KNAP's own server (apps.knapadvisory.com) — parsed in memory, never stored. Party-name lookups go from the server to the GST portal (services.gst.gov.in) and only the GSTIN→name cache is kept, shared by the whole team.
