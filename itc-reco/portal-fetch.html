Capture GSTR-2B / 2A from the portal

Runs in your own logged-in tab · never sees a password or an OTP · back to the reconciliation
Read this once. The GST portal publishes no API for taxpayers, so this works by watching what the portal itself does when you click Download, and repeating it for the other months. That is not something GSTN invites, and the endpoints it uses are not promised to stay the same — this can stop working overnight, and when it does it will say so rather than hand you a short file. Keep the pacing slow. If the portal starts refusing, stop and download by hand; it is your client's registration.

What it does, and does not

  • You log in and solve the captcha. The script has no part in it.
  • It never sees a username, a password or an OTP, and stores nothing — closing the tab is the whole cleanup.
  • It sends nothing anywhere. The ZIP it builds is assembled in your browser and saved by your browser.
  • It learns the portal's endpoints from your own click, every run. Nothing about GSTN's API is written into it.

How to run it

  1. Sign in at services.gst.gov.in and go to Returns Dashboard for the registration you want.
  2. Open the browser console — F12, then the Console tab. The first time, Chrome asks you to type allow pasting and press Enter before it will let you paste.
  3. Copy the script below, paste it into the console, press Enter. A small panel appears at the bottom right.
  4. Press Start watching, then download one month's GSTR-2B the normal way — the portal's own button.
  5. The panel fills in the month and GSTIN it saw. Tick the months you want, set the pacing, press Fetch and download ZIP.
  6. Drop that ZIP straight onto the reconciliation page. It reads a ZIP, and a ZIP of ZIPs.

Repeat per registration — each one is a separate login context on the portal.

When it does not work

  • “Nothing came back.” The recording probably missed the download itself. Press Clear and watch again, then click the portal's own Download button — not a page that merely shows the data.
  • Some months empty. Normal for months before the registration existed, or a return not yet generated. The panel lists which, and the reconciliation's own coverage check will say the same.
  • It stops partway. Slow the pacing down and run the remaining months again; the ZIPs can be dropped together.
  • Nothing at all happens. The portal may be blocking pasted scripts. Download by hand — the reconciliation takes the portal's ZIPs exactly as they come.
